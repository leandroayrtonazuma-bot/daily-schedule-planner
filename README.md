# 一日スケジュール自動生成アプリ

Google カレンダーの確定予定を土台に、入れてはいけない時間を除外し、ルーティンを先に配置し、
残った隙間にタスクを詰めて一日を組み上げる Web アプリ。

- 要件定義: [`PLAN.md`](./PLAN.md)
- 開発上の決定事項と進め方: [`CLAUDE.md`](./CLAUDE.md)

## 動かす

**かんたん（Windows）**: このフォルダの `スケジュールを開く.bat` をダブルクリックする。
初回だけ `npm install` が走り、準備ができるとブラウザが自動で開く。
黒い窓を閉じると停止する。

**コマンドから**:

```bash
npm install
npm run dev
```

<http://localhost:3000> を開く。

環境変数を設定していない間は**モックモード**で動く。
Google カレンダーには接続せず、[`mocks/calendar-events.json`](./mocks/calendar-events.json) の
ダミー予定を表示する。ログインも不要。

実データに切り替える手順は `CLAUDE.md` の「Phase 2 以降に入る前の準備」を参照。

## 画面

| パス | 内容 |
|---|---|
| `/` | 今日のタイムライン。ドラッグで移動、完了チェック、「今から組み直す」。前日までの残りは繰り越し確認が出る |
| `/tasks` | タスクの追加・編集・完了・削除。メモを貼ると AI がタスクに分ける |
| `/routines` | ルーティンの追加・編集・一時停止・複製・削除。許可時間帯は横棒で範囲選択 |
| `/settings` | 稼働時間、バッファ、休憩、見積係数、予定を入れない時間帯。実測が溜まると見積係数を提案する |

## 一日が組まれる順番

1. 稼働時間を空きとする
2. カレンダー予定を、前後のバッファごと差し引く
3. 予定を入れない時間帯を差し引く
4. ピン留め・完了済みの項目を確保する
5. ルーティンを置く（許可時間帯が窮屈なものから）
6. タスクを置く（Best-Fit。大きな空きを温存する）
7. 連続作業が続く箇所に休憩を挟む

置けなかったものは画面下部に出て、「バッファを5分にすれば入る」といった
具体的な緩和案が添えられる。自動では適用しない。

同じ入力なら必ず同じ結果になる。乱数も現在時刻も使っていない。

## AI によるタスク分解

`/tasks` の「まとめて貼り付け」にメモを貼ると、着手できる大きさのタスクに分かれる。

- **保存する前に必ず確認画面が出る。** 題名・見積・優先度をその場で直せるし、外せる
- `ANTHROPIC_API_KEY` が未設定なら、ボタンが無効になって理由が出るだけ。
  **手入力フォームは常に動く**
- API が落ちても、返答が JSON でなくても、例外にはせず「手で追加してください」と出す

## スマホから使う

PWA なので、ブラウザの共有メニューから「ホーム画面に追加」すると
ブラウザの枠なしで起動する。

**オフラインでは動かない。** Service Worker が持つのはアイコンや JS などの静的ファイルだけで、
ページ本体はキャッシュしない。予定の内容を端末に残さないため（PLAN.md 3.1）。

## データ

自分で作ったもの（設定・ルーティン・タスク・配置結果）は `data/store.json` に入る。
消せば初期状態に戻る。`.gitignore` 済み。

カレンダーの予定はどこにも保存しない。毎回 API から取り直す（PLAN.md 3.1）。
